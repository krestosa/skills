# Individual skills

The orchestrator loads individual skills on demand.

Each folder contains one `SKILL.md` with:

- role;
- personality;
- collaboration style;
- goal and success criteria;
- selection and exclusion criteria;
- canonical engine route boundary;
- tool and side-effect limits;
- output and stop rules.

The canonical engineering sources remain under `skills/skill-orquestador/` and are referenced rather than duplicated.
